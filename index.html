About this prototype

Built against the accompanying SIH 26108 blueprint (Smart Standard Engine). This build demonstrates the five must-demo mechanics end to end: hybrid retrieval, normative-reference graph expansion, evidence-bound confidence, outdated-standard detection, and BIS certification matching.

Dataset: 12 curated demo records (LED-luminaire cluster + a lighter cables cluster), hand-built to the blueprint's schema — not the full BIS catalogue. Scoring: a local JS engine standing in for the production bge-embeddings + BM25 + FAISS + cross-encoder pipeline, using the exact weighted formula from Section 10 of the blueprint.

LLM use: narrow and closed-book only — requirement extraction, and (on request) phrasing an already-computed evidence object. The model is never asked which standard applies. If the live API call is unavailable, extraction falls back to a local rules parser automatically.

Smart Standard Engine

Turn a specification into a defensible standard recommendation

Paste a spec or tender clause on the left, or pick one of the three seeded examples, then press Analyze specification. The system will:

  1. Extract structured requirements (product, power, IP rating, voltage, application)
  2. Retrieve and rank candidate Indian Standards using a hybrid lexical + semantic + attribute score
  3. Expand the top match through the normative-reference graph to surface allied standards
  4. Check any explicit "IS ####" citation against the amendment/supersession record
  5. Match mandatory BIS certification rules and show a confidence-scored, evidence-backed result
